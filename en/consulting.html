Consulting, data analysis and custom software

From a one-off analysis to an application in production: a single point of contact, regular deliveries, managed hosting.

Sports performance data analysis

I process your training and match data to answer a specific question: load trends, player comparisons, reading of a run of results. The deliverable is a short, reproducible report together with the scripts that produced it.

Dashboards

I design dashboards for coaching staff and management, fed automatically by your data sources. Indicators are chosen with you and documented.

Custom web applications

I build and maintain web applications that fit the way you work: data entry on the pitch, mobile access, automated reports, integration with data providers. Core stack: Python and Django, PostgreSQL, Docker.

Maintenance is part of the engagement: bug fixes, security updates, planned evolutions.

Hosting and security

  • Hosted on AWS in the Paris region, with daily backups.
  • Sensitive data encrypted at rest and in transit.
  • Monthly security audits, with fixes applied promptly.
  • Automated tests before every production release.

GDPR compliance

Athlete data is personal data, sometimes health data. Every project includes a record of processing activities, defined retention periods, need-to-know access rights and documentation handed over to the client. I can act as a data processor under the GDPR, with a data processing agreement.
